# Data Dictionary — GlowRoot Synthetic Dataset

All data in `01_data/generated/` is synthetic, generated by
`02_data_generation/generate_synthetic_data.py`, calibrated to real public
benchmarks documented in `02_data_generation/calibration_sources.md`.

Regenerate with: `python 02_data_generation/generate_synthetic_data.py`
(seeded — reruns are reproducible unless the seed is changed.)

---

## cities.csv (34 rows)

One row per city.

| Column | Type | Description |
|---|---|---|
| `city` | string | City name (real Indian cities) |
| `state` | string | State |
| `city_tier` | int (1/2/3) | Standard Indian city-tier classification |
| `population` | int | Simulated population, log-normal, tier-scaled |
| `income_index` | float | Relative income proxy, Metro = ~1.0 baseline |
| `internet_penetration` | float (0-1) | Calibrated to IAMAI-Kantar tier bands |
| `city_random_effect` | float | Unexplained city-level performance nudge |

## customers.csv (~42,000 rows)

One row per customer.

| Column | Type | Description |
|---|---|---|
| `customer_id` | string | Unique ID |
| `city` | string | FK to cities.city |
| `city_tier` | int | Denormalized for convenience |
| `signup_date` | date | First-order date |
| `acquisition_channel` | string | Meta Ads / Google Ads / Influencer / Organic-SEO / Referral |

## orders.csv (~108,000 rows, includes ~0.4% intentional duplicates)

One row per order. `delivery_days` has ~1.5% nulls; some `city` values have
inconsistent casing/spacing — deliberate, simulating real data-entry mess.

| Column | Type | Description |
|---|---|---|
| `order_id` | string | Unique ID (not unique across duplicated rows — dedupe in SQL) |
| `customer_id` | string | FK to customers.customer_id |
| `order_date` | date | |
| `city` | string | May have casing/spacing inconsistencies |
| `city_tier` | int | |
| `category` | string | Face Care / Body Care / Hair Care / Sunscreen / Combo-Kit |
| `order_value` | float (₹) | Right-skewed, log-normal |
| `is_cod` | bool | Cash-on-delivery flag |
| `is_returned` | bool | Return flag |
| `delivery_days` | float | ~1.5% null |
| `shipping_cost` | float (₹) | Scales with delivery_days |

## Known Data Quality Issues (intentional)

- `orders.delivery_days`: ~1.5% null
- `orders`: ~0.4% duplicate rows
- `orders.city`: ~1% inconsistent casing/spacing

## Table Relationships

```
cities (1) ───< customers (many)
customers (1) ───< orders (many)
marketing_spend: aggregates by (month, city_tier, channel) — joins via
  city_tier + month(signup_date), not a direct FK
```
